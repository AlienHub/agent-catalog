## 决策摘要

- **Command Code** → Command Code；add；active。建议以 Command Code 一条产品记录收录 CLI 和 Desktop beta 两种形态。taste-1 是官方模型/学习能力，不另建同名终端产品；cmd/cmdc 是平台命令别名。公开 issues/installer 仓库不是源码开放证明。未把官网 FAQ 的 free-tier 宣传替代当前详细价格页。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。

- **Cortex** → 身份未定；needs-review；unknown。仅有 Cortex 裸名不足以在多家互不相关产品中选定身份。保留 canonical_name/vendor/official_url/license/pricing/svg 为 null；要求补充候选官方 URL 或发布者后再处理，不把多个同名项目当作一个产品的 variants。这里唯一 variant 是消歧证据占位，不能发布为实际产品。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。

- **Crush** → Crush；add；active。收录终端编码 Agent，但当前源码归 source-available，而非普通 MIT。客户端自选模型模式的商业状态留 unknown；可选官方 Hyper 服务确有免费及付费层，单列以免把推理费用混成产品许可。官方 logo SVG 未取得，保持 null。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。

- **DeepAgents** → Deep Agents Code；add；active。建议只新增明确可直接使用的 Deep Agents Code / dcode。候选 DeepAgents 常指同名 SDK/harness；SDK本体不作为最终用户应用新增。旧 Deep Agents CLI 是官方 fork 来源，不作为严格同义别名。无独立应用现价声明，保留未知，不从 MIT 推断运行零成本。官方应用专属 SVG 未核实。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。

- **Firebender** → Firebender；needs-review；active。产品身份及付费插件形态已核实，但官方首页/博客目前均显示2026-10-31结束服务的公告，建议先 needs-review 或历史/即将停服区，并在发布时显著显示日期，不能无警告新增为长期活跃推荐。当前核验日2026-10-09尚未到终止日，因此标准状态记为 active，并在本说明保留计划终止日期。未核实独立地区版、应用源码仓库或官方SVG。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。 证据限制：停服日期仅由官方页面搜索索引/摘要交叉印证；本轮没有完整读取终止公告，不能把它表述为已通读公告全文。

- **ForgeCode** → ForgeCode；add；active。可新增ForgeCode主记录，区分Apache-2.0 CLI、依赖CLI的VS Code辅助扩展、专有的可选ForgeCode Services。旧 antinomyhq/forge 已重定向为 tailcallhq/forgecode，避免重复。价格证据跨2025旧套餐和2026服务免费声明，当前统一价格页未核实，所以所有当前commercial_status保持unknown；不把开源等同于免费。无独立地区发行证据；官方SVG未取得。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。 Services 的官方专有声明保存在 license 与来源解释；受标准字段枚举限制，其 source_classification 记为 unknown，而非声称其开源。

- **iFlow CLI** → iFlow CLI；needs-review；discontinued。不能作为仍活跃的免费 Agent 新增。建议进入 discontinued/历史目录或暂列 needs-review；若目录仅收活跃产品应排除。官方公告证明历史个人服务完全免费，但关闭后的当前总使用成本取决于自定义模型提供商，所以 commercial_status 仍留 unknown；不把心流AI助手会员或 Qoder 定价套给 CLI。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。

- **Jazz** → Jazz；add；active。按本批最终用户 Agent 范围，可新增 lvndry 的 Jazz CLI，并明确官网/仓库避免与 jazz.tools 数据库框架同名误合并。保留模型费用说明；聊天机器人是自托管入口，不推定存在原生手机或桌面 GUI 应用。官方 SVG 未核实，保持 null。 去重范围说明：未对现有仓库逐项去重；仅按本候选核实身份及官方形态。
