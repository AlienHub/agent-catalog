## 结论概览
- **Kode** → Kode CLI / add：独立候选；旧仓库 shareAI-lab/Kode 已重定向到 Kode-CLI；不要与 Kode Agent SDK 合并。作为终端编码 Agent 收录；旧 Kode 名称保留为别名，当前官方仓库名为 Kode-CLI。不要因 Claude 配置兼容或相似操作方式合并为 Claude Code，也不要把同品牌 SDK 当终端产品。商业模式与 SVG 未核实。
- **MCPJam** → MCPJam / needs-review：独立产品；不是 MCP 协议本身，也不是仅一个 SDK。身份与分发已核实，但核心定位是 MCP 测试、调试、评估平台，建议单独开发者工具区或人工确认产品收录边界；不能直接当通用自主 Agent。更不能因 README 简写 Apache-2.0 忽略 EE 许可 carve-outs。
- **Moxby** → Moxby / add：独立产品；Chat/Mods/Missions/Bridge 是同一产品功能/形态。应作为浏览器/电脑通用 Agent 收录；免费层不能标成免费 AI Agent，因为 Chat 与自主 Missions 不在免费层。桌面是可选 Bridge/companion，不能把历史整合浏览器 UI 宣传直接变成另一个现行产品。官方 SVG 未取得，保留 null。
- **Mux** → 身份未唯一确定 / needs-review：候选名存在多个不相关产品；原候选缺 URL，不能自动指定厂商。必须取得原候选 URL/厂商后才能归一化。若目标是 coder/mux，应以 Xum 为当前名、Mux 为历史别名；若是 usemux.ai，则是 Joel Christner 的 MIT 多形态编码 Agent；usemux.com 又是另一套产品。mux.com 是视频基础设施，也不能误收为同一编码工具。以上 variants 是消歧证据，不是一个产品的合并发行版。
- **Neovate** → Neovate / add：同一项目组织的不同 Agent 产品形态；老 Code Desktop 已归档，新的 Desktop 使用 Claude Code 后端。可收录 Neovate 家族，但需按分发区分 CLI、自有 VS Code 集成、新 Desktop、已归档老 Desktop。新 Desktop 使用 Claude Code，不能声称它就是旧 CLI 的新版 GUI。未找到正式定价页；MIT 不代表模型服务免费。官方站点有 SVG favicon 文件，但未确认其图形对应当前品牌，故产品 SVG 保留 null。 补充发行验证：Neovate Desktop v0.1.2 官方 release 确有 macOS ARM/Intel DMG 和 Windows x64 EXE；README 的 macOS quickstart 仍只属于 source-run/development，不能将两个证据混用。Neovate Assistant 仅 repo-verified，Marketplace 发布未核实。
- **Ona** → Ona / add：Gitpod 向 Ona 演进；Gitpod Classic 单独保留停服/迁移事实，不因已加入 OpenAI 合并成 Codex。Ona 是现行自主软件工程 Agent 平台，应保留与 Gitpod 的更名/迁移关系；Gitpod Classic PAYG 已 sunset。现属 OpenAI，仍有独立 Ona 品牌和销售入口，不因组织归属自动合并到 Codex。当前 pricing 已转 sales，未确认的旧 Free/Core 报价不要导入现行套餐。
- **Pochi** → Pochi / add：独立 AI 编码 Agent；不是 Tabby 代码补全服务器的别名。应收录 AI 编码 Agent，并拆分 IDE 包、CLI/root code 与托管服务许可证及商业模式。重点：IDE 包显式选择保留所有权利的独立 LICENSE.txt，即使官网自称 open-source、repo 根为 Apache，也不能简单将所有发行物标为 Apache。具体托管金额仍待复核。
- **Reasonix** → Reasonix / add：独立本地编码 Agent；1.x 稳定线与 2.x Studio 开发线并行；不是 DeepSeek 官方产品。可收录，多入口属于一个本地编码 Agent；保留 1.x/2.x 生命周期和平台差异。reasonix.io 官网 GitHub 指向 esengine/DeepSeek-Reasonix；搜索出现的 futureflowtech/reasonix 只是 fork，不能当官方仓库。reasonix.ai / reasonix.net 是另一个咨询/教育产品体系，也不要合并。公开源码 MIT 不证明模型推理免费；未找到产品正式价格表。 发布级补充：1.x desktop-v1.39.8 确有 Mac/Windows/Linux 安装包，现将其与全六目标 CLI 分开；2.x Studio 当前 studio-v2.33.0 release flag 为非 prerelease，仍保留官方 active-development 版本线说明。
