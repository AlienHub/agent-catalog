# 浏览器 AI 资产核验（2026-10-11）

## 范围与结果

基于 main 7f8166a：8 条浏览器插件，缺少主流侧栏、AI翻译、摘要和浏览器本体。

本批新增 **23 个独立应用**：**17 个浏览器插件、6 个 AI 浏览器 GUI（含 1 个已弃用历史资产）**；补充 **17 个 Chrome 商店 ID、9 个独立 Edge 商店 ID**。修复已有 QuillBot Web 与 Moxby 插件两条记录的 Logo。名称保持商店实际名称，不人为加形态括号；浏览器内嵌 AI 按浏览器本体 GUI 收录，每个本体只建立一个应用，不把 AI 功能重复拆成多个 GUI。

本批从原始 main 321应用/190产品新增23应用/21产品；与Web资产PR #2整合后为369应用/235产品；dataVersion 和 schemaVersion 未修改，由主代理统一发布。

- Glasp 高亮扩展和 YouTube Summary 是两个独立商店应用，但共享 Glasp 生态 product_id=glasp，不因扩展数量虚增产品数。
- ChatGPT Writer 官网页面现重定向 Jetwriter AI，按当前官方名称收录并保留旧名别名。Safari / Firefox 为 coming soon，不计入发布平台。
- TextCortex 的官方帮助只给 Chrome 构建，明确支持 Edge/Opera/Brave/Vivaldi；平台支持不等于存在独立 Edge 商店条目，其 Edge ID 留空。
- AIPRM for Claude 官方页面目前也链接 AIPRM for ChatGPT 的同一个 Chrome ID，故不重复建立第二应用。
- Opera 官网已将浏览器内嵌 AI 称为 Opera AI；Aria 保留历史别名，不使用旧品牌作为另一个应用。Opera Neon 为独立本体和独立产品。
- Dia 官网及 [Windows 1.1.0 更新说明](https://www.diabrowser.com/changelog/windows/1-1-0)确认 Windows 于 2026-10 已发布；不沿用旧的仅 macOS 平台印象。
- Microsoft Edge 仅列本次核验的 Windows/macOS AI 场景，不从下载页支持 Linux 推断 Copilot Mode 在 Linux 等价可用。功能可能按市场、账号及版本变化。
- 独立的商业字段只在官方商店明确标注应用内购买或官方套餐页面直接给出付费服务时补录；未知不是免费或非商业。未推断当前商店扩展开源许可。

## Logo 原始资产

素材的原始 URL、SHA-256、格式、字节数、PNG尺寸与应用关联见 [素材清单](browser-ai-assets-2026-10-11.json)。Comet 独立SVG原样提取自官方品牌指南的 Logo ZIP，清单记录归档成员路径，不采用黑白双栏PNG样张。Chrome 扩展 PNG 使用商店明确列出的 `srcset` s120 URL，原样保存，无格式转换。SVG只收独立矢量；Dia官网favicon.svg内嵌位图，因此拒绝作为 SVG 并改收官网原始PNG。Edge使用SVGL固定提交原始SVG，保留 `licenses/svgl.txt`。

官网、商店素材仅用于产品识别；公开可下载不等于商标授权，品牌权利归各自权利人；未从仓库代码许可证推断官方 Logo 授权。PNG状态明确包含“未收录 SVG”和“PNG（位图）”，不计入SVG统计。
