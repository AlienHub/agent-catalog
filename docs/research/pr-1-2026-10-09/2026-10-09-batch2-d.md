# Agent Atlas 第二批 D 组核查

核查日期：2026-10-09。仅采用厂商官网、文档、官方仓库/许可证；未安装或运行任何候选软件。

## 结论

- Rovo Dev：仍运营但已公告独立产品 sunset；CLI/IDE 最终退役日期待定。12 月 3 日仅 Code Reviewer 计费迁移。
- Roo：规范名 Roo Code；2026-05-15 扩展已停运并归档。仅作为历史待审记录，不加入活动目录，Apache-2.0 只覆盖核实的扩展代码。
- Tabnine CLI：真实官方终端 Agent，不能与 Tabby 合并；官网已转向 Tricentis，当前现售价格需复核。
- TerraMind：候选身份 needs-review；已核实 terramind.com 的 Nucleus/Spaces 应用，但无原规则 URL，不能自动映射，须与 IBM 同名地球观测模型消歧。
- TinyCloud：基础设施/SDK 范围，needs-review。EGPL 有生产限制，不能标成 OSI 开源。
- Zencoder 与 Zenflow：同厂共享订阅的并列产品；IDE 插件与桌面 Code/Work 分开记录，不误判为纯改名。
